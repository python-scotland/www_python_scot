# www-python-scot

The python.scot website.

[https://python.scot](https://python.scot)

### Tech

* Flask
* Tailwindcss
* AlpineJS
* Docker

### Development Environment

(uv and npm are required)

Install environment

```bash
uv sync
```

```bash
npm i
```

Run Flask + Tailwindcss

```bash
uv run qwe dev
```
